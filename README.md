# 🎮 Hashira Adventurer

A 2D mobile game developed using **Godot 4** for an Emerging Technologies course project.

Fight slime enemies, track your progress, and challenge the **Lower Moon Demon** in an exciting boss battle!

## ✨ Features

- Main menu and volume controls
- Slime enemies and a boss battle
- Player health bar and kill counter
- Victory and Game Over screens
- Offline gameplay
- Virtual joystick for mobile controls

## 🛠️ Technologies Used

- Godot 4
- GDScript

## 🚀 Future Improvements

- More playable characters
- Multiple difficulty levels: Easy, Hard, and Expert

## 📚 About the Project

Developed as a Computer Engineering course project. This project helped me explore mobile game development and improve my programming skills. I plan to continue improving the game by adding more features and gameplay options.
